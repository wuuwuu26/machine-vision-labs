**运行说明（如何复现实验）**  
本文件从 README 中拆出，专门说明如何复现 MVSNet / DTU scan9 立体匹配与三维重建实验。  
   
 环境要求见 README §1；目录结构见 README §2。  
***GPU 限制*** *：阶段 1（深度估计）与 fusibile 融合都必须在* ***有 GPU 的宿主机*** *上运行；当前 WorkBuddy 沙箱未透传 * */dev/nvidia** *，只能跑可视化 / 报告（纯 CPU）部分。*

**1. 阶段 1 — 深度估计（需 GPU，宿主机运行）**  
bash /home/user/rvclab2/run_stage1.sh  
   
该脚本等价于课件命令：  
/home/user/miniconda3/envs/mvsnet3/bin/python MVSNet/mvsnet/test.py \  
   --dense_folder /home/user/rvclab2/dtu_test_scan9/scan9 \  
   --regularization '3DCNNs' \  
   --max_w 1152 --max_h 864 --max_d 128 \  
   --interval_scale 1.06 --gpu_memory_fraction 0.9 \  
   --pretrained_model_ckpt_path /home/user/rvclab2/tf_model_blendedmvs_200301/tf_model_blendedmvs/3DCNNs/model.ckpt \  
   --ckpt_step 150000  
   
- 输出：写入 dtu_test_scan9/scan9/depths_mvsnet/（深度图 + 概率图，分辨率 288×216）。  
- 受 8 GB 显存限制：max_d=192 会 OOM，已降为 128。

**2. 阶段 2 — 点云融合（原版流程，宿主机运行）**

该脚本等价于课件命令：  
python MVSNet/mvsnet/depthfusion.py \  
   --dense_folder /home/user/rvclab2/dtu_test_scan9/scan9 \

- 同时生成 B 档点云（供图 3 左 / 指标计算）：

**5. 注意事项**  
1. **改报告正文要改 ** **exp2_make_docx.py**：报告内容（文字、表格、图引用、字体）全部内置于该脚本，并不读取任何 .md；改 .md 不会反映到 docx。  
2. **页数估算仅供参考**：exp2_page_estimate.py 仅按文本长度估算高度， **不含 Word 真实行距/段距**，会显著低估。真实页数请在 Word / LibreOffice 中打开确认（当前约 5 页）。  
3. **字体**：报告正文中文字体为  **Noto Serif CJK SC**，西文/数字为 Times New Roman，标题为黑体。  
4. **fusibile/** ** 是被实际调用的**：阶段 2 通过 depthfusion.py → fusibile 二进制完成几何融合，编译依赖离线 CUDA 12.4 工具链（/home/user/cuda124）。CUDA 12.1 安装包与 runfile 已清理，请勿用 12.1 重新编译（Ubuntu 24.04 不兼容）。  
5. **dtu_test_scan9** ** 与 ** **tf_model_*** ** 是大文件**：前者为数据集 + 阶段输出，后者为模型权重，均属运行必需，勿删；其中 points_mvsnet/consistencyCheck-* 与 point_cloud_prob_filtered.ply 是报告图 3 的数据来源。
