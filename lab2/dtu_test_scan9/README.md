# DTU scan9 data (not tracked)

This folder is a placeholder for the DTU MVS scan9 dataset used by Lab 2.

Expected layout after downloading and preparing the data:

```text
lab2/dtu_test_scan9/
└── scan9/
    ├── images/            # 49 views, 1600×1200
    ├── cams/              # camera parameters, one .txt per view
    ├── pair.txt           # view pairing for cost-volume construction
    ├── depths_mvsnet/     # generated by MVSNet test.py
    └── points_mvsnet/     # generated by depthfusion.py + fusibile
```

Download the DTU MVS dataset from:

<https://roboimagedata.compute.dtu.dk/?page_id=36>

The MVSNet preprocessing script (`lab2/MVSNet/mvsnet/preprocess.py`) converts the DTU format into the layout above. See `lab2/运行说明.md` for the exact commands.

The dataset is excluded from git because it contains thousands of images plus multi-GB depth maps and point clouds.
