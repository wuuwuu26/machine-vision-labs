## 2. 从相对深度到米制深度：仿射逆深度对齐

Depth Anything V2 的**相对深度**版本输出的是**仿射不变的逆深度** `q`，它只保留了场景深度的相对次序，不含绝对尺度。要得到米制深度并与真值比较，必须做一次最小二乘拟合：

```
1 / depth_gt = a · q + b
```

在 `valid` 像素上解出 `(a, b)`，再由 `z = 1 / (a·q + b)` 还原成米，最后截断到 [0.1, 10]。

**这一步是整个评估的关键**：(a, b) 这两个自由度是**用真值本身拟合出来的**。因此下面报告的所有"相对深度"精度数字，都建立在"已知真值可做一次全局标定"的前提上，这不是一个真正零标定的结果——这一点在第三节与 Metric 版本对比时会重新讨论。

## 3. 逐图指标

三项指标定义：

- **AbsRel（对齐后绝对相对误差）**= `mean(|z − g| / g)`
- **Depth RMSE** = `sqrt(mean((z − g)²))`，单位米
- **XYZ RMSE** = 把预测与真值各自用内参 `K` 反投影成点云 `P`、`G`，再算 `sqrt(mean(‖P − G‖²))`，单位米

其中 `z` 为对齐后的预测深度，`g` 为真值深度，均在 `valid` 掩码内统计。

| nyu_0101 | 0.1657 | 0.6835 | 0.7280 |
| nyu_0201 | 0.1025 | 0.8289 | 0.8748 |

## 4. 结果分析

**整体精度**：均值 AbsRel 0.0755、Depth RMSE 0.374 m、XYZ RMSE 0.399 m。对单目深度估计而言这是合理水平——注意该模型**未在 NYU 上训练过**，属于零样本迁移。

**逐图差异很大**，AbsRel 从 0.0262（nyu_0001）到 0.1657（nyu_0101），相差 6 倍以上。观察真值分布可以看出原因：

- 表现最好的 nyu_0001（AbsRel 0.0262）真值范围仅 1.80 ~ 3.64 m，中位数 3.05 m，**场景深度跨度小**，对齐后容易拟合。
- 表现最差的 nyu_0101（AbsRel 0.1657）与 nyu_0201（AbsRel 0.1025）真值都**延伸到 10 m 截断**，中位数分别只有 1.48 m 和 2.58 m，说明场景既有很近的物体又有很远的背景，**深度动态范围大**。仿射对齐只能在逆深度空间做线性变换，对这种大跨度场景的拟合残差明显更大。

**XYZ RMSE 与 Depth RMSE 高度一致**（0.3986 vs 0.3738，比值约 1.07），说明误差主要来自沿视线方向的深度误差，反投影到三维后横向误差贡献很小。这符合预期：像素坐标由内参直接决定，没有横向自由度。

**点云可视化**：把 `z` 与 `g` 各自用 `K` 反投影，配合原图 RGB 着色，导出为 `.ply`，共 16 个文件（8 张图 × 预测/真值）。由于只保留 `valid` 像素，点云是稀疏的（每张约 16.5 万 ~ 23 万点），空洞位置对应 Kinect 的深度缺失区。
