## 1 实验设置

本实验在 NYU Depth V2 的 8 张室内 RGB 图像（640×480）上完成三部分内容：用 Depth Anything V2 做单目深度预测；将输出经仿射逆深度对齐恢复为米制深度并反投影生成点云；在有效像素域上评估 AbsRel、Depth RMSE 与 XYZ RMSE 三项指标。在此基础上比较输入分辨率 518 与 280 的差异，并引入 Depth Anything V2 的 Metric Depth 版本作对照。主要配置见表 1，数据集概况见表 2。

**表 1　实验配置**

| 项目 | 配置 |
| --- | --- |
| 模型与权重 | Depth Anything V2 ViT-Small（24.8 M 参数）；相对深度版权重 depth_anything_v2_vits.pth；对照实验用 Metric 版权重（Hypersim 微调，输出上限 20 m） |
| 输入分辨率 | 默认 518；分辨率对比实验取 280（两者均为 patch 尺寸 14 的整数倍） |
| 测试数据与真值 | NYU Depth V2 教学样例 8 张（MATLAB 编号 1 / 101 / … / 1201）；真值为与 RGB 配准的 Kinect 实测深度 rawDepths（米），随附有效像素掩码 valid |
| 有效域 | 深度有限且 0.1 < Z < 10 m，且位于 ROI [45:471, 41:601]，合计 1 649 818 像素 |
| 运行环境 | Python 3.12 + PyTorch 2.7.1（CUDA 12.8），NVIDIA RTX 4060 Laptop 8 GB，Open3D 0.19.0 |

评估口径：模型输出 q 是仿射不变的逆深度，不含绝对尺度，因此先在 valid 像素上最小二乘拟合 1/z = a·q + b 得到一组 (a, b)，再由 z = 1/(a·q + b) 恢复米制深度并截断到 [0.1, 10] m。相机内参为 fx = 518.858、fy = 519.470、cx = 324.582、cy = 252.736（0 起始像素坐标），预测与真值点云用同一套 K 反投影，三项指标均在 valid 掩码内统计。需要强调的是，(a, b) 是用真值本身拟合出来的，因此本文所称"相对深度精度"反映的是**对齐后的几何质量**，不能理解为模型零标定、独立预测绝对距离的精度。无效像素主要来自 Kinect 在反光、透明与超量程区域的缺失；真值上限 10 m 是数据集自身的截断，nyu_0101、nyu_0201、nyu_0801 三张图的有效像素中出现了 10.00 m 的取值。
